# Module 5 – Collections & Data Structures

Building collections of data using arrays, structs, enums, unions, and multidimensional arrays.

This module focuses on how real programs organize information in memory instead of relying on individual variables.

## Projects

- `project26-player_inventory_system` – Manual list management using arrays and a count variable
- `project27-bubble_sort` – Sorting integers with the Bubble Sort algorithm
- `project28-rpg_text_battle` – Simulating combat using structs
- `project29-user_account_database_and_lockout` – Array of structs acting as a simple database with account locking
- `project30-gradebook` – Nested arrays inside structs for storing multiple grades
- `project31-grid_dungeon_map` – Representing a game world using a 2D array
- `project32-cinema_seat_booking_system` – Interactive seat reservation using a 2D array
- `project33-tictactoe_win_checker` – Detecting winning board states with row, column, and diagonal checks
- `project34-network_packet_parser` – Using enums and unions to interpret different packet payloads

## Covered

- Static arrays
- Array indexing and contiguous memory
- Manual list management with a count variable
- Linear searching
- Bubble Sort
- Structures (`struct`)
- Arrays of structures
- Nested arrays inside structures
- Enumerations (`enum`)
- Unions (`union`)
- Struct padding and memory alignment
- Two-dimensional arrays
- Row-major memory layout
